# 仕様 (SPEC)

## 1. 目的
ツール名は「看板屋」（実行ファイルは `KanbanYeah.exe`）。
Windows 版 InterPot3 の看板エディタ（編集モード）に、任意の画像を自動で描く。描いた後の「保存」はユーザーが自分で行う。

## 2. 前提（原作の看板エディタ）
出典: 原作クライアント `ipv3m4.jar` の `interpot.client.board` パッケージ（`EditCanvas` / `PenTool` / `LotSignBoardView`）

| 項目 | 値 |
|---|---|
| 描画領域 | 320 x 240 px、24bit（`int[] pixels`, 0x00RRGGBB）。画面に 1:1 で表示される |
| パレット | 10 色（下表）。色ボタンを押すと `EditCanvas.setColor` |
| ペン | 1 / 4 / 8 px。1px ペンは押下点を `drawLine(x,y,x,y)`、ドラッグ中は**直前の点から `drawLine`** で結ぶ |
| CLR | 現在色で全面を塗りつぶす（`fillRect`） |
| Undo | マウス押下ごとに `pixels` を `undoBuf` に退避（1 段のみ） |
| 保存 | `pixels` をそのまま 24bit で保存（PPM + gzip）→ パレット外の色も保持される |

パレット（`LotSignBoardView.createEditToolPanel`、2 段 x 5 列）:

| | 列0 | 列1 | 列2 | 列3 | 列4 |
|---|---|---|---|---|---|
| 段0 | 黒 `#060606` | 灰 `#939393` | 白 `#FFFFFF` | 桃 `#FFB595` | 赤 `#FF0500` |
| 段1 | 水 `#3ACDFF` | 青 `#0205CA` | 黄 `#FFDD00` | 緑 `#00BB09` | 茶 `#C26B15` |

## 3. 機能
### 3.1 看板の作成（編集機能、詳細: `docs/design/features.md`）
看板は下から「下地 → 画像 → スタンプ・文字（z 順）」の重ね合わせ。各機能は 1 タブ（Feature）。
- **画像**: PNG / JPEG / BMP / GIF を開く（ファイル選択・ドラッグ&ドロップ・exe への引数）。合わせ方: **全体を収める** /
  **トリミングして埋める** / **引き伸ばす**。余白・透明部分には下地が見える。
- **下地**: 無地（10 色）またはフレーム。フレームは画像を登録時に 320x240 に配置し、その時点の減色設定で 10 色にして保存・保持する
  （右クリックで削除）。フレームの色は減色・ディザの影響を受けない。
- **スタンプ**: 画像を登録・保持（任意で「背景を消す」〔既定オフ〕、透明な余白を切り詰め）。登録できるのは切り詰め後 320×240
  まで（大きいものは登録しない）。ファイル選択で複数まとめて登録でき、大きさ違反のものは個別に飛ばす。看板には等倍
  （dot by dot = 100%）で置き、
  看板上でドラッグ移動・角で拡縮・つまみで回転（Shift で 15°）、つまみで大きさ・角度、前面へ・背面へ・削除。
- **文字**: 文字の形は 2 通り。
  - **公式と同じ（ドット文字）**: InterPot の文字ツールと同じ字形（英数字 = Arial、日本語 = MS ゴシックのドット版）。サイズは
    公式と画素単位で一致する 10〜22px（公式の既定は 12px）。太字・回転・拡縮はできない（公式ツールにもない）。
    InterPot を動かしている Java（.jar を開く Java）で描くので公式と同じ。その Java が無いときは Windows で近い形（日本語は同じ、
    英数字は 1〜数画素違う）。
  - **フォントを選ぶ**: インストール済みのフォント、サイズ 6〜200px、回転。
  共通: 太字、色（10 色）、縁取り（なし / 10 色、幅 1〜5）。アンチエイリアスなし・パレット色のみで描き、にじまない。
- 看板上: クリックで選択、矢印キーで 1px（Shift 10px）移動、Delete で削除。元に戻す / やり直し（Ctrl+Z / Ctrl+Y）。
- 表示は 1 倍。編集中はフルカラー（配置が軽い）。**「下書き」**で減色して実際に描く 10 色の絵と本数・目安時間を作り、表示を
  「カラー / 下書き（10 色）」で切り替える。下書き後に編集すると下書きは古くなる（描画開始・PNG 保存では自動で作り直す）。
  「PNG 保存」で 320x240 の 10 色画像を保存。

### 3.2 減色
- 10 色パレットへ減色。色差は知覚的な距離（CIELAB の ΔE76）。
- ディザ: なし / Floyd–Steinberg / Atkinson / 組織的ディザ(Bayer 4x4)。強さ 0–100 %。
- 使う色を個別に ON/OFF できる（例: 茶を使わない）。
- 前処理: 明るさ・コントラスト・彩度の調整（画像とスタンプのみ。つまみは Windows 標準、上の ▼ で既定値に戻る）。

### 3.3 看板の自動検出
- 画面全体（全モニター）をキャプチャし、**パレットの 10 色ボタンの配置**を探してキャンバスの左上を求める
  （キャンバス内容に依存しない）。キャンバス・ペン・CLR の位置はパレットからの固定オフセット。
- 見つからない / 複数ある / 隠れている → 理由を表示して描画しない。

### 3.4 描画
- 手順: ① 1px ペンを選ぶ ② CLR に最適な色（全色を試して最少になる色）を選んで CLR（全面塗り）③ 残りの色を 1 色ずつ選び、
  横（または縦）のランを 1 ストローク = 「始点で押す → 終点で離す」で描く ④ 画面を読み戻し、目標と違う画素を描き直す（最大 3 回）。
- **重ね塗り最適化**: 後で描く色に塗られる画素は「どの色でもよい」とみなし、ランを長くつなげる（ストローク数削減）。
- ラン方向は色ごとに横 / 縦の少ない方を選ぶ。
- 入力方式:
  - **バックグラウンド（既定）**: ゲームのウィンドウにマウスメッセージを直接送る（PostMessage）。実マウスを動かさないので
    描画中もマウスを使える。ゲームの処理速度に自動で合わせる（約 2ms/ストローク）。
  - **マウス操作（互換）**: 実マウスを動かす（SendInput）。1 ストロークごとに同期するので遅い（約 18ms/ストローク）。
- 進捗表示（色・ストローク数・割合）、推定所要時間の表示。
- 中断後は「続きから / 手直し」で、画面の今の状態から違う画素だけ描く。

### 3.5 安全装置
- **Esc**（どのウィンドウが前面でも）、画面の「中止」で即中断。
- 看板が見つからなくなった（移動・隠れた・閉じた）、ゲームのウィンドウが閉じた → 中断。
- バックグラウンド方式: ゲームのウィンドウ内を物理的にクリックしたら中断。
- マウス操作方式: マウスを動かした・クリックした、ゲームが前面でなくなった → 中断。
- 中断時は必ずマウスボタンを離す。開始前に 2 秒のカウントダウンと位置の再確認。
- 「保存」はツールは押さない（ユーザーが確認して押す）。

## 4. 非機能
- Windows 10 (1903+) / 11、x64/x86。**追加ランタイム不要**（.NET Framework 4.8 は OS 標準）。単一 exe。
- 管理者権限不要（ゲームも通常権限で動くため）。
- 高 DPI: ツールは Per-Monitor V2 で物理ピクセルを扱う。ゲーム（Java 8）が拡大表示されている場合は検出時に警告。
- 設定（最後のフォルダ、ディザ、入力方式など）は `%APPDATA%\KanbanDrawer\settings.txt`。

## 5. 旧ツール（WinXP 時代のファンメイド）からの改善点
| 旧方式 | 本ツール |
|---|---|
| 1 ドットずつクリック | 1px ペンの「押した点から離した点へ線を引く」仕様を使い、同色ランを 1 ストロークで描く |
| 白から全部描く | 最適な色で CLR してから描く。後続色で上書きされる画素を跨いでランを延長、縦横を選択（約 51,600 → 20,227 回、ディザなしなら約 52,000 → 5,387 回） |
| 実マウスを奪う | ゲームのウィンドウに直接メッセージを送る。描画中もマウスを使える |
| 描きっぱなし | 画面を読み戻して差分だけ描き直す（取りこぼしに強い）。続きから再開も同じ仕組み |
| 固定座標 | パレット配置からの自動検出、Per-Monitor DPI 対応、マルチモニター、他ウィンドウの重なりに強い入力先の決定 |
| 中断しにくい | Esc・ゲームのクリック・看板消失で即中断 |
| 減色は最近傍のみ | 知覚色差 + 3 種のディザ + 使用色選択 + 明るさ等の調整 + プレビュー + 所要時間の目安 |
