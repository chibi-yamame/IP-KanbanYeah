# 画面・CLI

## 画面（`UI/MainForm`、ウィンドウ名「看板屋」、クライアント 744x690、最小 700x630〔外寸〕）
- 左（常設）: `EditorView`（看板 1 倍 + 余白）、**下書き** ボタン + 表示切替（カラー / 下書き（10 色））、元に戻す / やり直し /
  PNG 保存 / **貼り付け**（同じ行。クリップボードの画像・テキストを看板に置く。描画中は無効。押したときにクリップボードを読む
  ので、中身に応じた有効・無効の切り替えはしない）、統計（下書きのストローク数・色切替・目安・塗りつぶし色 → 色順。下書きがない / 古いときは案内文）、入力方式 +
  看板を検出（1 行）、**フルカラー用の 2 行**（状態の行・InterPot3.jar の行。入力方式が「フルカラー」のときだけ）、描画開始、続きから / 手直し、中止、進捗バー、ログ（残りの高さいっぱい。左パネルの Resize で合わせる。**既定のウィンドウで 6 行以上、フルカラーモード（2 行増える）でも 5 行以上**見える）。
- 入力方式は 3 つ: バックグラウンド（推奨）/ マウス操作（互換・遅い）/ **フルカラー（直接書き込み・実験的）**（`Modes` の 3 番目、設定 `input` = 2）。
  フルカラーの詳細は [fullcolor.md](fullcolor.md)。選んだとき:
  - 入力方式の行の下に 2 行（`StackPanel` の行、他の入力方式では非表示 = 高さを取らない）:
    - 状態の行: 左に**状態**（ラベル。「未接続」/「未接続（別の看板屋が使用中）」/
      「接続中: エディタなし」/「接続中: エディタあり」/「版が合いません」。`AgentLink.StatusChanged` で更新）、右に 2 つのボタン
      **「InterPot を起動」**（フルカラー用に起動 = `GameLauncher.Launch`）・**「ショートカットを作成」**（デスクトップに .lnk = `GameLauncher.CreateShortcut`）。
    - InterPot3.jar の行（高さ 26）: 左に**今の場所**のラベル（`InterPot3.jar: ` + 短い形 `GameLauncher.ShortPath`〔`…\InterPot3\InterPot3.jar` のようにフォルダ名 1 つ + ファイル名。
      ドライブ直下なら `C:\InterPot3.jar`〕。マウスを載せるとツールチップにフルパス。設定 `fullcolor.jar` が空なら「InterPot3.jar: 未設定」、
      ファイルがなければ短い形の後ろに「（見つかりません）」）、右に **「変更...」**ボタン。「変更...」= `GameLauncher.ChooseGame` のファイル選択
      （今の場所、無ければ自動で見つけた候補を選んだ状態。キャンセルなら何も変えない）→ 確定したら `fullcolor.jar` に保存してラベルを更新。
    - 初回（`fullcolor.jar` が空、または指すファイルがない）に「InterPot を起動」/「ショートカットを作成」を押すと、先に同じファイル選択が出る
      （自動で見つけた候補が選ばれている。決め打ちで黙って使わない）。確定した場所だけ保存する。キャンセルならログ「InterPot3.jar が見つかりません」で何もしない。
  - 「看板を検出」・「続きから / 手直し」は無効、統計欄の文は「フルカラーで書き込みます（10 色に減色しません。下書きは使いません）」。
    編集の表示は今まで通りカラー（下書きの表示切替・「下書き」ボタンはそのまま使える。書き込みには使われない）。
  - 「描画開始」→ `StartFullColor`: カウントダウンなし。状態が「接続中: エディタあり」でなければ、ログに理由を出して何もしない（下表）。書き込み中（応答待ち、最大 10 秒）は
    「描画開始」と編集を無効にする。
  - 看板屋を閉じるとき、`AgentLink` は後始末する（接続を閉じ、サーバーを止める）。ゲームは閉じない。
- フルカラーのログ（ASCII でない固定文。接続の変化もログに出す）:
  | 場面 | ログ |
  |---|---|
  | 接続した（初回の HELLO） | ゲームの連携プログラムとつながりました |
  | 切れた | ゲームとの接続が切れました |
  | 状態が `Disconnected`・`Busy`・`Mismatch` で描画開始 | ゲームとつながっていません。「InterPot を起動」でフルカラー用に起動してください（ゲームを先に起動済みなら、一度閉じて起動し直し）／別の看板屋が使用中です／連携プログラムの版が合いません |
  | `NoEditor` で描画開始 | InterPot で看板の編集画面を開いてください |
  | 版違い（接続時に 1 回） | ゲーム側の連携プログラムの版（n）が看板屋と合いません。「InterPot を起動」で起動し直してください |
  | 書き込み成功 | フルカラーで書き込みました。看板を確認して、「保存」はご自身で押してください。 |
  | `ERR none` | エディタが閉じられたため書き込めませんでした |
  | `ERR <理由>` | ゲームがエラーを返しました: <理由> |
  | 応答なし（10 秒） | ゲームが応答しません（接続を切りました） |
  | 起動 | InterPot を起動しました（フルカラー用）。ログインして看板の編集画面を開くと、状態が「接続中: エディタあり」になります |
  | `InterPot3.jar` が選ばれない・Java がない・起動に失敗 | InterPot3.jar が見つかりません／InterPot を動かす Java（.jar を開くプログラム）が見つかりません／起動できませんでした: <メッセージ> |
  | ショートカット | デスクトップにIP起動用リンク「InterPot3 (屋)」を生成しました（パスは出さない） |
  | ショートカットの作成に失敗 | ショートカットを作れませんでした: <メッセージ> |
  | エージェントの jar が内蔵されていないビルド | この看板屋にはフルカラー用の連携プログラム（kanban-agent.jar）が入っていません |
- **ログ欄の高さ**（左パネルは上から積み、ログが残りを取る）: ログの上端 = 6（余白）+ 260（看板）+ 34 + 34（ボタン 2 行）+ 56（統計）+ 32（入力方式）+ 40（描画開始）+ 34（続きから / 中止）
  + 20（進捗バー）+ 3 = 519px、下の余白 6 + 3。よって**ログの高さ = クライアント高 − 528**。クライアント高 600（旧）→ 72px（Yu Gothic UI 9pt の 1 行 ≈ 18px で約 4 行）だった。
  **690 にする → 162px = 約 8 行**（6 行 ≈ 112px を余裕をもって上回る）。フルカラーでは 2 行（34 + 30 = 64px）が増えて 98px = **約 5.4 行（5 行 ≈ 94px 以上）**。
  最小サイズは高さを同じだけ（+90）上げて 630（外寸。旧 540）、幅 700 はそのまま。実装では 1 行の高さを `log.Font.Height` で確かめ、
  既定で `6 * Font.Height + 4` 以上、フルカラーで `5 * Font.Height + 4` 以上になること（フォントが違って足りなければクライアント高を増やす）。
  ログの最小高 48px のクランプはそのまま。
- 描画開始から実際の描画までのカウントダウンは 2 秒（`MainForm.CountdownSeconds`、CLI `--countdown` の既定も 2）。
- 編集はフルカラー表示、「下書き」で 10 色の描く絵を作って表示（[features.md](features.md)「入口・流れ」）。描画開始・PNG 保存は
  下書きが古ければ作り直してから使う。
- 右: Feature のタブ（`FeatureRegistry`。下地 → 画像 → スタンプ → 文字 → 減色、起動時は下地）。各タブの中身は [features.md](features.md)。
- オブジェクトを選ぶと、それを扱う Feature のタブに切り替わる（`IFeature.Owns`）。
- キー: Ctrl+Z / Ctrl+Y（Ctrl+Shift+Z）= 元に戻す / やり直し（文字入力中を除く）。Ctrl+V = 貼り付け（同じ規則で、TextBox / ComboBox / NumericUpDown にフォーカスがあるときはその欄の
  普通の貼り付けのまま。描画中は何もしない）。看板上の操作は `EditorView`。
- 貼り付け（Ctrl+V / ボタン、`MainForm.Paste`）: `Clipboard.GetDataObject()` を `ClipboardContent.Read` で読み、画像ファイル →
  画像データ（PNG のアルファは保つ）→ テキストの順で最初に見つかったものを、画像は「画像」タブ・テキストは「文字」タブの Feature
  （`IAcceptsPaste`）に渡す。何もなければログに「貼り付けられるものがありません」。詳細は [features.md](features.md)「クリップボードから貼り付け」。
- 画像ファイルのドロップ: 表示中のタブが `IAcceptsFiles` ならそこへ、違えば「画像」タブへ。exe への引数 1 個も同じ。
- 描画中はタブ・看板・undo を無効化。ゲームと重ならない画面の隅に `ProgressOverlay`（最前面・非アクティブ化・クリック透過）。
- 目安時間 = ストローク数 × 方式別の実測値（Post 2.3ms、Send 18ms）+ 色切替 × 0.15 秒 + 2 秒。

## 設定（`UI/Settings`）
`AppPaths.DataDir\settings.txt`（key=value）。全体: `input`（0 = バックグラウンド、1 = マウス操作、2 = フルカラー）, `fullcolor.jar`（`InterPot3.jar` のフルパス。既定は空。
空・ファイルがないときは、「InterPot を起動」/「ショートカットを作成」で、自動で見つけた候補〔アンインストール情報 → 既定の場所〕を選んだファイル選択を出し、
利用者が確定した場所だけを保存する。状態の行の「変更...」でも変えられる → [fullcolor.md](fullcolor.md)）, `tabName`（前回のタブをタブ名で。順番が変わってもずれない。
旧版の `tab`〔番号〕は読まない）。Feature ごと: `picture.fit`, `folder`（画像）、`dither`, `strength`, `colors`（減色）、
`frame.*`, `stamp.*`, `text.*`。壊れていても既定値で起動する。

## CLI（`Program.Cli`）
```
KanbanYeah.exe 画像                 … 画面で開く
KanbanYeah.exe --draw 画像 [--fit contain|cover|stretch] [--dither none|fs|atkinson|bayer] [--strength 0-100]
                 [--bg RRGGBB] [--input post|send] [--delay ms] [--click-delay ms] [--fence n] [--retouch n]
                 [--countdown s] [--save-quantized out.png] [--log file] [--debug-shot out.png]
KanbanYeah.exe --quantize 画像 --save-quantized out.png [オプション]
KanbanYeah.exe --detect
KanbanYeah.exe --compare a.png b.png
KanbanYeah.exe --register-stamp 画像 [--remove-bg]          … 320x240 を超えると終了コード 1
KanbanYeah.exe [--fit ...] --register-frame 画像 [--remove-bg]   … 配置して保存するだけ（減色オプションは効かない）
KanbanYeah.exe --dotfont-dump dir 10-22 chars.txt                         … 公式文字の調査用（GDI の字形を書き出す）
```
終了コード: 0 = 完成（`--compare` は一致）、1 = 一致しない画素が残った（不一致）、2 = 中断、3 = エラー / 見つからない。
親コンソールがあれば出力（UTF-8）、`--log` でファイルにも。CLI の `--draw` は画像 1 枚だけ（スタンプ・文字は画面から）。フルカラー（直接書き込み）は画面だけ（CLI なし）。

## 環境変数
| 変数 | 意味 |
|---|---|
| `KANBANDRAWER_DATA` | 設定・ライブラリの置き場所（既定 `%APPDATA%\KanbanDrawer`）。テストはここを差し替えてユーザーのライブラリを汚さない |
| `KANBANDRAWER_PIPE` | フルカラー連携のパイプ名（`\\.\pipe\` の後ろ。既定 `KanbanYeah-<ユーザーの SID>`）。テスト用（[fullcolor.md](fullcolor.md)） |
| `KANBANDRAWER_TRACE` | 描画のトレース（パス・フェンスの待ち時間/タイムアウト・ボタン確認・読み戻し）を追記するファイル |
